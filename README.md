# Haim Amar Market News

Repository used as the publishing data source for the bilingual daily market brief on haimamar.co.il.

Files:
- `market-news.json` — Hebrew feed
- `market-news-en.json` — English feed
- `market-news-archive.json` — Hebrew archive
- `market-news-archive-en.json` — English archive

The feed schema will be aligned with the existing site before the site is switched to read from this repository.
